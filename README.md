# PeopleBoard – Senior Angular Developer Exercise
## Overview
PeopleBoard is a small user-management dashboard. It has a dashboard, a people directory, and individual user profile pages. The application uses local mock data to simulate an API; no backend or credentials are required.
## Run locally
Prerequisites: Node.js 20.19+ (or a version supported by Angular 20) and npm.
```bash
npm install
npm start
```
Open the local URL printed by Angular CLI (normally http://localhost:4200).
To run the available lint command:
```bash
npm run lint
```
To create a production build:
```bash
npm run build
```
## Exercise
Review the application as if you had inherited it from another engineering team. Improve its quality, reliability, maintainability, performance and user experience.
You should decide how to approach the work. You are not expected to rewrite the entire application. Prioritise changes that provide the greatest benefit, and be prepared to explain your decisions and any trade-offs.
Please provide:
- Your updated source code.
- A short summary of the issues you found and addressed.
- A note explaining any issues you deliberately left unresolved and why.
- A brief explanation of the most important technical decisions you made.
You may add tests, documentation or tooling where you believe they add value. You do not need to implement a real backend.
## Product behaviour
- **Overview:** headline people metrics, department distribution and recently active people.
- **People:** searchable, sortable and filterable directory.
- **Person profile:** view contact details and edit basic profile information.
- **Mock data:** the user service provides sample records with a simulated network delay.
## Constraints
- Keep the application focused on the supplied product scope.
- Do not introduce a real backend or external service dependency.
- You may use Angular and RxJS features you consider appropriate.
- You may change the structure of the application if you can explain why.
## Suggested time
Allow approximately 3–4 hours. This is a guide rather than a hard limit.
